## Features

- **Professional Grade**: Specialized roles designed for industry-standard engineering.
- **Plug & Play**: Simply add the `.skill` files and invoke them via `/`.
- **Architectural Integrity**: Focus on clean code, scalability, and security.
- **Workflow Optimized**: Covers the entire SDLC from planning to deployment.

---

## How to Use

To invoke a skill within Claude Code, use the `/` command followed by the skill name:

```bash
/senior-architect  # Plan your system design
/senior-backend    # Implement robust APIs
/code-reviewer     # Get a rigorous audit
```

## Recommended Workflow

1. **Plan**: `/senior-architect` → `/writing-plans`
2. **Build**: `/senior-backend` or `/frontend-design`
3. **Verify**: `/code-reviewer` → `/senior-security` → `/senior-qa`
4. **Polish**: `/impeccable` → `/finishing-a-development-branch`

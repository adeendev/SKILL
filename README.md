## �📥 Installation

Getting started is incredibly easy. Choose your preferred method:

### 1. Direct Download (Easiest)
Simply download the `.skill` files you need and place them in your project's root directory or your Claude Code skills folder.

### 2. Git Clone
```bash
git clone https://github.com/Adeen/SKILL.git
```
Then, copy the `.skill` files into your active project.
